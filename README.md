# Ryan Bryant | Cybersecurity Portfolio

Welcome to my cybersecurity portfolio. This repository documents hands-on projects and case studies developed to strengthen my skills across security operations, governance and risk, vulnerability assessment, endpoint investigation, security automation, incident response, and technical reporting.

My goal is to demonstrate not only technical cybersecurity skills, but also the ability to analyze findings, assess business risk, recommend remediation, and communicate security information clearly to both technical and non-technical stakeholders.

## Featured Portfolio Work

### Cybersecurity Risk & Governance Assessment
Conducted a simulated organizational cybersecurity risk assessment for Northstar Financial Group. The project includes asset criticality analysis, stakeholder interviews, an 11-finding risk register, business-impact analysis, remediation priorities, control ownership, and preliminary NIST CSF 2.0 alignment.

### Security Operations Investigations
Developed multiple SOC-focused investigations using tools such as Wazuh, Wireshark, Suricata, osquery, and Linux security controls to analyze network activity, investigate endpoint behavior, correlate evidence, and document findings.

### Security Automation
Built Python-assisted alert triage workflows and Wazuh Active Response scenarios to demonstrate repeatable investigation, correlation, automated containment, validation, and recovery.

### Vulnerability and Network Analysis
Performed controlled reconnaissance, vulnerability assessment, network analysis, and service enumeration within authorized lab environments and documented technical findings with recommended remediation.

### Stakeholder Communication
Created professional case-study reports and stakeholder presentations that translate technical cybersecurity findings into operational risk, business impact, and recommended actions.
